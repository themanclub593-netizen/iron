# IRON

แอปบันทึกการฝึกเวทส่วนตัว (PWA ไฟล์เดียว) เปิดบน iPhone แล้วเพิ่มไปที่หน้าโฮมได้

- ข้อมูลการฝึกทั้งหมดเก็บในเครื่องที่เปิดแอปเท่านั้น ไม่ได้อยู่ใน repo นี้
- สำรองข้อมูลได้ที่แท็บ ตั้งค่า แล้วกด ส่งออก
- โค้ช AI ใช้ Claude API key ที่ใส่ในแอป key เก็บในเครื่องนั้นเท่านั้น ไม่อยู่ใน repo และไม่อยู่ในไฟล์สำรอง
- อัปเดตแอป: แทนที่ไฟล์ `index.html` แล้วรอ GitHub Pages สร้างเว็บใหม่ราว 1–2 นาที
